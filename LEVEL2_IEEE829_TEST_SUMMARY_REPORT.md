## 3. Seeded Defect Inventory & Architectural Remediation

### Defect 1: Coupon State Accumulator Memory Leak (`BUG-78` / `TC-109`)
- **Severity:** Critical | **Module:** Cart / Pricing (`CartContext.js`)
- **Root Cause:** When `REMOVE_COUPON` is dispatched, the reducer subtracts the discount from the accumulator without clearing the applied coupon reference, leading to compounding discounts on re-application.
- **Architectural Fix:** Enforced atomic state reset: `discount: 0, appliedCoupon: null`.

### Defect 2: Broken Typo Navigation Route `/suport` (`BUG-79` / `TC-107`)
- **Severity:** Medium | **Module:** Routing / Navigation (`Footer.jsx`)
- **Root Cause:** Misspelled route destination `/suport` in footer component triggers client-side 404 catch-all view.
- **Architectural Fix:** Aligned navigation target to canonical `/support` endpoint.

### Defect 3: Unauthenticated Barrier on Public Coupon API (`BUG-80` / `TC-108`)
- **Severity:** High | **Module:** Authentication Middleware (`/api/coupons/validate`)
- **Root Cause:** Public promotional coupon validation requests demanded authenticated Bearer tokens, preventing guest learner checkout evaluation.
- **Architectural Fix:** Added public route exemption to authentication interceptor.

### Defect 4: Checkout createOrder Parameter Mismatch (`BUG-81` / `TC-110`)
- **Severity:** Critical | **Module:** Payment Checkout (`CheckoutModal.jsx`)
- **Root Cause:** The `createOrder` network payload transmits the un-discounted subtotal in the `amount` field while the UI displays the net discounted price.
- **Architectural Fix:** Synchronized network payload: `amount: Math.round(cart.total * 100)`.

### Defect 5: Quiz Multi-Select State Persistence Loss (`BUG-82` / `TC-111`)
- **Severity:** High | **Module:** LMS Assessment (`QuizPlayer.jsx`)
- **Root Cause:** Question switching logic overwrites the answer array with single scalar primitives, wiping multi-choice answers.
- **Architectural Fix:** Implemented persistent answer state dictionary keyed by question ID.

### Defect 6: Certificate Gating Client-Side Bypass (`BUG-83` / `TC-112`)
- **Severity:** Critical | **Module:** Microcredentials (`CertificateView.jsx`)
- **Root Cause:** Direct URL navigation to `/certificates/:id` loads certificate documents without server-side score authorization.
- **Architectural Fix:** Enforced cryptographic passing score barrier prior to rendering document DOM.

### Defect 7: Orders List Endpoint 404 Discrepancy (`BUG-84` / `TC-113`)
- **Severity:** High | **Module:** Orders History (`apiClient.js`)
- **Root Cause:** Client requests `/api/orders` while the backend microservice router exposes `/orders`.
- **Architectural Fix:** Normalized API base URL mapping across all account history views.

### Defect 8: Mentor Booking Slot Double-Reservation Race Condition (`BUG-85` / `TC-114`)
- **Severity:** Critical | **Module:** Mentor Scheduling (`bookingController.js`)
- **Root Cause:** Non-atomic read-modify-write pattern allows concurrent requests to reserve identical mentor time slots.
- **Architectural Fix:** Implemented transactional mutex lock returning HTTP 409 Conflict on concurrent slot claims.

### Defect 9: Password Complexity Validation Disparity (`BUG-86` / `TC-106`)
- **Severity:** Medium | **Module:** Learner Registration (`RegisterModal.jsx`)
- **Root Cause:** UI form validation permits 6-character alpha passwords while backend API strictly demands 8+ characters with special symbols.
- **Architectural Fix:** Synchronized client regex with backend policy: `^(?=.*[A-Za-z])(?=.*\d)(?=.*[@$!%*#?&])[A-Za-z\d@$!%*#?&]{8,}$`.

### Defect 10: Razorpay Mock Signature Client-Side Exposure (`BUG-87` / `TC-110`)
- **Severity:** Critical | **Module:** Payment Security (`PaymentModal.jsx`)
- **Root Cause:** Client JavaScript bundle calculates mock payment verification hashes locally, exposing signature generation logic.
- **Architectural Fix:** Delegated payment signature verification exclusively to backend cryptographic microservice.

### Defect 17: Support Ticket Replies: Unhandled Reply Error Swallows API Failure and Retains Stale State (`BUG-94` / `TC-131`)
